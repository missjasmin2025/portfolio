## Overview

This is a **professional, minimalist portfolio landing page** designed to showcase my skills, projects, and technical approach. The site emphasises:

- **Clean, semantic HTML**  
- **Modern CSS** with responsive layouts, custom properties, and dark/light mode  
- **Vanilla JavaScript** for interactivity, theme toggling, smooth scrolling, animations, and a back-to-top button  
- **Accessibility-first design** (ARIA roles, skip links, focus management)  
- **Performance and maintainability**, ensuring the site is easily extensible for future projects

The primary project highlighted is **this landing page itself**, which demonstrates both technical skill and careful design decisions.

---

## Features

- **Hero section**: Clear introduction with name, role, mission statement, and call-to-action buttons  
- **About section**: Detailed summary of skills, technical stack, and professional traits  
- **Projects section**: Highlights portfolio page as a production-ready project with complexity explanation  
- **Contact section**: Professional contact information (email, GitHub, LinkedIn)  
- **Dark/Light toggle**: User preference persisted with localStorage  
- **Smooth scrolling & fade-in animations**: Provides a polished, interactive user experience  
- **Back-to-top button**: Floating and accessible  
- **Responsive & minimalist design**: Optimised for all devices
